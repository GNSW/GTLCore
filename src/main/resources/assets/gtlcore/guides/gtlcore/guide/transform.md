# 旋转、镜像与阵列

## **旋转与镜像**

在复制、移动模式的“**编辑变换**”中，设置绕 X、Y、Z 轴旋转或对应轴镜像。旋转每次 **90°**：左键 **+90°**，右键 **−90°**；镜像点击切换开关。

* X、Z 轴旋转改变竖直方向，Y 轴旋转用于水平转向。
* 某些方块无法表示请求的垂直旋转状态，工具会提示旋转不受支持。
* 带方块实体的设备不支持旋转或镜像移动。
* 变换后核对目标尺寸；不一致时，重新标记粘贴位置。

## **阵列**

在“**设置阵列**”中分别填写 X、Y、Z 三轴的数量和额外间距。

* **阵列数量**：该轴生成的份数，包含第一份；总份数为三轴数量相乘。
* **额外间距**：两份结构外框之间的间隔。0 表示贴合，正数表示留出相应格数。
* **排列方向**：世界坐标各轴的正方向，步长为变换后结构尺寸加额外间距。

多份复制不能使用负间距造成重叠。阵列成倍增加用料和工程规模，**移动只允许各轴数量为 1**。

## **重置变换**

点击“**重置变换**”，旋转归零、关闭镜像、阵列数量恢复为 1、额外间距恢复为 0。源和目标坐标保留。
