# 网络绑定、供料与回收

## **绑定与解绑**

按设置键打开菜单，选择“**网络绑定 → 绑定网络**”；菜单关闭后，持工具右键已接入网络的 <ItemLink id="ae2:wireless_access_point" />，完成绑定。

* 绑定后支持无限距离、跨维度物流，无需额外携带无线终端。
* 被绑定的无线访问节点须保持区块加载，网络须可用且有电。
* “解除绑定”移除关联。已有工程记录了启动时的绑定，更换网络前应先取消旧工程。

跨维度物流只影响物料和供能，世界选区的施工仍须在源选区所在维度进行。

## **取料与回收顺序**

* **提取物品**：ME 网络优先，不足部分从背包提取。
* **提取流体**：ME 网络优先，不足部分尝试从背包中可用的流体容器提取。
* **回收物品**：ME 网络 → 背包 → 现场掉落。
* **回收流体**：ME 网络 → 背包中可接收的流体容器；剩余部分保留在工程暂存。

## **物料页面**

“**物料**”页面显示工程剩余物料，可通过“上一页”“下一页”翻页，下方显示工具电量及网络绑定状态。该页面也提供四类建造材质和替换白名单设置。

## **供能**

工具使用 EU，充电等级为<Color color="#FF0000">**ZPM**</Color>，默认容量 **100 亿 EU**。施工优先使用工具电量，不足部分可由绑定 ME 网络的真实能源补足。

硬度、设备类型及玩家到作业位置的距离影响消耗，靠近作业区域有助于降低耗能。

## **自动补料**

施工时会检查剩余材料，网络具有对应合成样板、基础原料和可用 CPU 时，可自动申请缺口材料。

松开右键暂停世界施工，正在计算或已提交的 AE 请求仍可能继续处理。使用“**计划与下单 → 取消自动下单**”停止相关请求；再次长按恢复普通工程会重新启用自动补料。
