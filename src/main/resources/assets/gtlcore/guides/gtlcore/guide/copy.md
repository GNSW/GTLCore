# 复制

选择“**复制**”模式或按 **Ctrl＋C**，标记源 A、B；选择“标记粘贴选区”或按 **Ctrl＋V**，选定目标位置后，潜行长按右键执行。

## **源与目标**

* **标记源选区**：选择“复制 → 标记源选区”或按 Ctrl＋C，清除粘贴目标并切回源标记。原有源坐标保留，需要清除时使用“清除坐标”。
* **标记粘贴选区**：选择“复制 → 标记粘贴选区”或按 Ctrl＋V，重新选定目标；工具自动按源经过变换后的尺寸生成目标范围。
* **变换与阵列**：通过“编辑变换”和“设置阵列”调整方向及份数。
* **目标占位**：按当前移除规则处理已有方块。

复制保留源结构，在工程启动扫描时读取源数据。源和目标区块都须已加载，世界操作位于源选区所在维度。

## **材料与设备**

复制消耗目标方块、附加组件及已适配库存对应的真实物料，可以通过“计划与下单”准备。

设备配置和关联按适配情况恢复。**复制样板总成会生成绑定原总成的镜像**；样板供应器、P2P 和无线集线器的处理条件见“设备配置与关联处理”。
