# 菜单与快捷键

设置界面的打开按键默认为 **G**：持有工具时按 G 打开菜单；右键保留给选点和施工。其余快捷键使用下列默认绑定，调整后以游戏控制设置及物品提示为准。

## **菜单操作**

* **打开物质操纵者设置**：可在“控制设置 → GTLCore 物质操纵者”中修改绑定。主手或副手持有工具时，按设置键打开环形菜单，选择模式和设置。
* **环形菜单**：点击扇区展开或选择；点击中心或按 Esc 返回上一级。
* **下方入口**：分别打开“物料”“网络绑定”“计划与下单”和“工程控制”。

选点或施工时，直接按 G（或自定义菜单键）打开菜单；若把菜单键改回右键，需先松开右键。

## **选点与施工**

* **普通右键方块表面**：选择点击面外侧相邻一格。
* **潜行＋右键短按后松开**：选择命中的方块本身；也可对准空气补点，位置以预览和坐标为准。
* **潜行＋右键按住 1.5 秒**：启动或恢复工程，准星旁圆环显示启动进度。启动后保持右键施工，松开右键暂停。

## **选区快捷键**

* **Ctrl＋C**：切换到复制模式，标记源选区。
* **Ctrl＋X**：切换到移动模式，标记源选区。
* **Ctrl＋V**：进入粘贴选区标记，重新选择目标位置。
* **Ctrl＋Z**：清除源、目标坐标。

快捷键只修改模式和选区设置，实际施工需要长按启动。**Ctrl＋Z 不撤回施工**，撤回入口位于“工程控制”。

## **方块采样**

* **鼠标中键**：采样准星指向的方块状态，统一设置角、棱、面、内部四类材质。
* **潜行＋鼠标中键**：将准星指向的方块状态加入替换白名单。
