# 替换与白名单

按设置键打开菜单，选择“**替换**”，标记 A、B，设置白名单、形状和目标材质，潜行长按右键执行。

工具处理选区内同时符合形状和白名单的位置，按角、棱、面、内部分类放置目标材质。

## **白名单操作**

* **世界采样**：对准来源方块，按潜行＋中键，加入实际方块状态；可重复添加多个来源。
* **光标物品加入白名单**：在“替换白名单”菜单或“物料”页面操作，使用光标方块的默认状态；空光标加入空气。
* **清空替换白名单**：删除全部来源。**空白名单默认只匹配空气**。

白名单按方块状态匹配，朝向、含水等状态不同，需要分别添加。

## **目标与占位**

通过“设置方块”、中键采样或“物料”页面指定目标材质，操作方式与建造模式相同。

目标材质可设为空气，用于移除白名单内的指定方块。替换已有实心方块时，将移除规则设为“**全部移除**”；加入白名单本身不会允许拆除已有占位。
