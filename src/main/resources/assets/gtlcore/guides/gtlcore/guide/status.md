# 工程状态与限制

工具提示和菜单下方显示当前状态、完成数量及相关坐标。

## **等待状态**

* **扫描与规划中**：正在读取选区、设备数据和用料。
* **等待材料／合成**：检查剩余物料，补充匹配的物品或流体；自动补料需要样板、基础原料和可用 CPU。
* **等待电量**：为工具充电，或确保绑定网络有足够能源。
* **等待绑定网络**：检查绑定节点是否已加载，网络是否可用且有电。
* **等待区块加载**：加载源、目标及相关设备区块；工具不会主动加载远处区块。

## **冲突与错误**

* **目标占位不符合移除规则**：调整目标或移除规则，取消旧工程并重新规划。
* **粘贴选区尺寸不一致**：核对源尺寸与变换，重新标记粘贴位置。
* **目标或移动源状态已变化**：按提示坐标检查，取消旧工程后重新规划。
* **网络绑定已变化**：取消旧工程，再使用当前网络创建工程。
* **存在不支持的方块实体**：部分设备可能被跳过，其他位置可能已施工；检查现场并单独处理遗留设备。
* **撤回冲突**：相关方块、设备数据或网络关联已有变化，按提示位置检查后处理剩余撤回。

## **工程规模**

* 默认单工程上限为 **65,536 格**。复制阵列按源长方体体积乘总份数计算，空位置也计入扫描规模。
* 设备数据和撤回记录共同受默认 **64 MiB** 快照预算限制，超限时可分段施工。
* 默认目标速度为每秒 **1,024 次操作**，实际速度受服务器预算、区块、设备复杂程度、材料和电量影响。

容量、规模、快照预算、速度和预览等参数可由模组配置调整，以所在服务器设置为准。世界操作须位于建造高度、世界边界内，区块已加载，并通过相应权限检查。
