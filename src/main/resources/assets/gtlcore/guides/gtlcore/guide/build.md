# 建造、形状与材质

按设置键打开菜单，选择“**建造**”，标记 A、B，在“设置形状”和“设置方块”中指定施工内容，潜行长按右键执行。

工具以源选区为施工范围，按形状筛选位置，放置对应分区的材质。材料从绑定 ME 网络或背包提取。

## **设置形状**

在“建造 → 设置形状”中选择；替换模式也提供相同设置。

* **直线**：连接 A、B，支持斜线，使用“棱”材质。
* **长方体**：按角、棱、面、内部分类放置方块。
* **圆柱**：沿 Y 轴生成，X、Z 尺寸控制横截面，Y 尺寸控制高度。
* **球体**：由选区包围生成，三轴尺寸不同时形成椭球。

## **设置方块**

角、棱、面、内部四类材质分别控制对应位置，可独立设置或统一采样。

* **中键采样**：对准世界方块按中键，将实际方块状态应用到全部四类材质。
* **设置方块菜单**：点击分区，使用光标上的方块；光标为空时使用副手方块。使用物品指定时取方块默认状态。
* **物料页面**：从下方背包拿起方块，点击分区按钮，使用方块默认状态；空光标指定空气。

薄层结构同样按角、棱、面分类，全部位置使用同种方块时，可用中键统一设置。

**空气材质会把对应位置设为空气**；内部设为空气可形成空心结构。已有占位仍须满足移除规则。

## **移除规则**

在菜单中选择“移除规则”，设置如何处理目标已有方块：

* **仅可替换方块**：默认规则，可清理草等可替换占位，普通实心方块会阻挡工程。
* **不移除**：不拆除已有占位，用于在空位置施工。
* **全部移除**：允许覆盖已有方块，仍受权限、不可破坏方块及设备支持范围限制。

该规则也影响替换、复制和移动的目标区域。已满足要求的普通方块可直接跳过；拆除模式按其自身范围处理。
