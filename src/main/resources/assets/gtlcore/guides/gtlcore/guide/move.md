# 移动

选择“**移动**”模式或按 **Ctrl＋X**，标记源 A、B；选择“标记粘贴选区”或按 **Ctrl＋V**，选定目标位置后，潜行长按右键执行。

“标记源选区”或 Ctrl＋X 可切回源标记，清除粘贴目标并保留源坐标；其他选区编辑方式与复制相同。

## **移动行为**

工具将原有方块及已支持设备的数据转移到目标，施工过程中逐步清空源位置。目标已有方块按移除规则处理。

移动转移原物料，不像复制那样额外生成一份结构；施工仍消耗电量。

## **使用限制**

* 源、目标区域不能重叠。
* 各轴阵列数量必须为 **1**。
* 带方块实体的设备不支持旋转或镜像移动，移动设备前在“编辑变换”中重置变换。
* 源和目标须位于同一维度，相关区块须已加载。
* 源状态变化会停止工程，需检查提示位置，取消后重新规划。

移动样板总成会更新已登记镜像的引用；不支持的设备须单独处理。
